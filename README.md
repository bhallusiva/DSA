# 🧠 Data Structures & Algorithms — Java

A structured collection of **LeetCode solutions in Java** for developing problem-solving skills and preparing for software engineering placements.

The goal of this repository is not just to collect solved problems, but to build strong understanding of **patterns, algorithms, time complexity, space complexity and edge cases**.

## 🧩 How I Approach Problems

For each problem, I aim to understand:

1. What pattern does the problem use?
2. What is the brute-force approach?
3. Can the solution be optimized?
4. What are the time and space complexities?
5. Which edge cases can break the solution?
